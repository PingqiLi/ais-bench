# BBH
## 数据集简介
BIG-Bench（Srivastava等人，2022年）是一个多样化的评估测试集，其重点关注当前语言模型被认为尚无法完成的任务。尽管语言模型已在该基准测试中取得显著进展——BIG-Bench论文中的最佳模型通过少量示例提示（few-shot prompting），在65%的任务上超越了人类评估者的平均成绩。但究竟在哪些任务上语言模型仍落后于人类平均水平？这些任务是否真的超出了当前语言模型的解决能力？
